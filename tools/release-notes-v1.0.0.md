# KlinRead v1.0.0

手机版首个正式版本。数据层与手表版（KlinRead for Watch）同步。

## 界面：Apple 风格设计系统

配色与排版改为 Apple 的系统规格：

- **中性色用 Apple 系统灰**（浅色 `#F2F2F7` 页面 + 纯白卡片；深色 `#1C1C1E` 页面 + `#333336` 卡片）。
  之前整个界面是粉色调，页面与卡片亮度只差 5%，卡片几乎看不见 —— 换中性色后层次才出来。
- **强调色保留粉色**（`#8E2A5E`），用于主按钮、选中态和角标。
- **8pt 网格**：所有间距为 8 的倍数（4dp 为唯一半步，用于光学微调）。
- **负字距**：标题 -0.022em、正文 -0.011em。
- **圆角**：按钮 12、卡片 20、小元素 8。
- **按下反馈**：可点元素按下缩放到 0.96。

### 书架改为封面网格

从竖向列表改成 **3 列封面网格**（手表版 2 列）。封面按 2:3 书籍比例，阅读进度条叠在封面底边。

## 功能

| 功能 | 说明 |
|---|---|
| **书架分类** | 全部 / 未读 / 在读 / 读完 + 自定义分类，每个带实时数量 |
| **封面** | 导入时提取并缓存缩略图；无封面的格式用生成的占位图 |
| **读完标记** | 读到最后一章最后一段自动标记；封面右上角「完」角标 |
| **阅读统计** | 今日阅读时长与累计时长 |
| **音乐** | 可导入本地音轨，支持 MP3 / FLAC / AAC 等；阅读时自动播放 |
| **多种格式** | EPUB / TXT / HTML / UMD / MOBI |

## 本版修复

- **中文 TXT 打不开**：格式嗅探读固定 4096 字节窗口，中文按 3 字节算，窗口几乎必然切在字符中间，UTF-8 校验因此失败，报「无法识别的文件格式」。现已在判定前对齐到字符边界（含「窗口停在首字节」这一形态）。
- **文件重复打开**：解析一本书要开 2–3 次 URI，部分文件管理器只给短暂授权，第二次返回 null。现改为只打开一次。
- **音乐失效音轨静默失败**：源文件被删除或移动后，点击播放没有任何反应。现在会明确提示「找不到这个音轨」，并加了 8 秒准备超时兜底。
- **音乐搜索无效**、**歌曲一直显示已选中**。

## 已知问题

**EPUB 阅读进度识别有误** —— 进度条和「未读 / 在读 / 读完」可能与实际读到的地方不符。书架顶部有提示条标注，下个版本修复。TXT 不受影响。

## 安装

```
adb install -r KlinRead-v1.0.0.apk
```

> debug 签名，安装前如遇签名冲突需先卸载旧版。
